# White_Dwarf_Photosynthesis

This repository contains the Python scripts used to generate the figures in Chitnavis et al. (2026).

### Figures

1. **PAR Flux (0.6 M☉)**
   Photosynthetically Active Radiation (400–700 nm) across the habitable zone of a representative 0.6 M☉ white dwarf. For example, at WD 1856+534 b (~0.02085 au, ~6.85 Gyr), FPAR ≈ 400 μmol photons m⁻² s⁻¹.

2. **Excitation Delivery Rate (0.6 M☉)**
   Excitation delivery rate from a typical antenna to a typical "photosystem" reaction centre, ν. At WD 1856+534 b, ν ≈ 1500 s⁻¹, exceeding the maximum turnover rate of oxygenic photosynthesis (νmax ≈ 100 s⁻¹).

3. **Required Antenna Size (0.6 M☉)**
   Number of antenna pigments required to maintain νmax = 100 s⁻¹. At WD 1856+534 b, Np ≈ 50 pigments per PSII.

4. **PAR Flux (0.9 M☉)**
   Equivalent calculation for a 0.9 M☉ white dwarf.

5. **PAR Flux (0.3 M☉)**
   Equivalent calculation for a 0.3 M☉ white dwarf.

The 0.3 and 0.9 M☉ cases yield qualitatively similar conclusions to the representative 0.6 M☉ model presented in the paper.
